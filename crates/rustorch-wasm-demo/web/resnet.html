ResNet basic block GPU only — experimental

Smoke-test of the convolutional kernel chain: conv → bn → relu → conv → bn + skip → relu. The input is a deterministic [1, C_in, H, W] tensor; the output is shown as a per-channel heatmap so you can see the spatial pattern the block computes.

⚠ This page exercises the WGSL kernel pipeline directly. On macOS Metal the chain currently has stability issues that can crash the tab — the demo is wrapped in a 10-second hard timeout so a stuck kernel aborts cleanly instead of eating all your RAM. If it times out, prefer the CPU live training demo or the CPU encoder block, which run on the same WASM bundle without WebGPU.
