What's happening, in 60 seconds

  1. We sample 64 noisy points from y = sin(x) on [-π, π] — those are the blue dots.
  2. A tiny multilayer perceptron Linear(1 → H) → ReLU → Linear(H → 1) starts with random weights — the red curve starts as a wiggly mess.
  3. Each step computes the mean-squared error between its prediction and the noisy targets, runs backpropagation through rustorch's autograd tape, then takes one SGD update.
  4. After a few hundred steps the red curve hugs the green truth — the network has generalized past the noise. The loss curve on the bottom chart traces the descent.
  5. Crank Hidden units up to overfit; drop Learning rate too low to watch the descent stall; pump Noise to see the model find the underlying signal regardless.
