ResNet block — WebGPU demo

Runs a single basic ResNet block on a synthetic [1, C_in, H, W] F32 input. Uses random (deterministic, seeded) weights. Returns the [1, C_out, H, W] output as a Float32Array. Real ResNet-18 inference with HuggingFace weights lands in a follow-up via load_safetensors_to_js.
