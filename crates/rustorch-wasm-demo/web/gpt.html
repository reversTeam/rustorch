GPT-style block — WebGPU demo

Runs one transformer block (LayerNorm → causal multi-head attention → residual → LayerNorm → FFN+GELU → residual) on a character-level prompt. Returns the activation of the last position as a Float32Array.

v1 uses random seeded weights and one ASCII byte = one token. This is not a real GPT-2 with BPE + 124M trained weights — it's a structurally accurate end-to-end demonstration of the WGSL kernel pipeline.
