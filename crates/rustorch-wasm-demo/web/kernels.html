rustorch — browser demo gallery

Pure-Rust deep-learning library compiled to WebAssembly. Each card below exercises a specific corner of the public API, from raw GPU kernels (WebGPU) to autograd-aware training in the browser (CPU).

GPU WebGPU compute path   CPU autograd-aware path (no GPU required)   TRAIN exercises forward + backward + grad processing

⚠ The GPU demos exercise the raw WGSL kernel chain via wgpu-22. On macOS Metal that path currently has stability issues that can hang the tab — every GPU button below is wrapped in a 10 s hard timeout so a stuck kernel aborts cleanly instead of crashing the page. The CPU demos run on the autograd stack and are stable; for a real learning demo see the live training page.

Build & serve

./build.sh        # produces pkg/ next to web/
python3 -m http.server 8080
# open http://localhost:8080/web/ in Chrome 120+

The CPU demos (encoder, pool, training) work in any browser with WASM support — they don't depend on WebGPU. The GPU demos require Chrome 120+ with WebGPU enabled.
