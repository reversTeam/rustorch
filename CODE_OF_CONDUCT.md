# Code of Conduct

This project adopts the **Contributor Covenant version 2.1** verbatim as its
code of conduct. The full canonical text is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project (issues, pull requests, discussions, chat,
events), you agree to abide by its terms.

## Scope

The Code of Conduct applies in all project spaces: this repository, GitHub
discussions, official chat channels, project events, and any space where an
individual is representing the project or its community.

## Reporting

To report a concern, please email **conduct@rustorch.dev**.

Reports are reviewed and addressed by the project maintainers in
confidence. The maintainers will not retaliate against anyone reporting
in good faith.

If a maintainer is the subject of the concern, contact another maintainer
directly so the report is handled by an uninvolved party.

## Enforcement

Maintainers follow the **Contributor Covenant Enforcement Guidelines** —
the four-tier process documented at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines>

In short: the response scales from a private correction to a permanent ban,
proportionate to the severity and pattern of the conduct.
