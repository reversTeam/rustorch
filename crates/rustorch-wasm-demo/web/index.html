rustorch — browser WebGPU demo

Phase 2 deliverable

This page calls into a WASM module compiled from crates/rustorch-wasm-demo. It allocates two F32 tensors of shape [B, K], runs add → relu → softmax on the browser's WebGPU adapter via the rustorch-wgpu crate, and reads the result back to JS as a Float32Array.

Build: wasm-pack build crates/rustorch-wasm-demo --target web
